# Virage

> **Catégorie : PRODUCT.** Virage est une vitrine web statique publique dédiée à la présentation de cartes de collection à vendre.

## État

Le dépôt contient actuellement une page `Index.html` et ne fournit ni paquet de dépendances ni procédure de construction automatisée. Sa maintenance doit donc rester proportionnée : vérifier le contenu publié, la validité des liens et l’accessibilité de la page avant toute évolution commerciale.

## Exploitation locale

Ouvrir `Index.html` dans un navigateur ou le servir avec un serveur de fichiers statiques. Aucun identifiant, moyen de paiement ou secret ne doit être ajouté dans le dépôt client.

## Décision de portefeuille

Le projet est conservé au niveau P3 comme produit statique. Le propriétaire doit décider s’il reçoit un cycle de maintenance éditoriale et une solution de vente adaptée, ou s’il devient candidat à l’archivage ; aucune modification de visibilité ni archivage n’est effectué ici.
